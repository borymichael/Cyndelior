# Modèle de brief

Copiez ce bloc, remplissez ce que vous savez (le reste peut rester vide) et envoyez-le à Claude Code.

```text
[NOUVEAU PROJET]

CLIENT :
ACTIVITÉ :
OBJECTIF :
CIBLE :
LOCALISATION :
SERVICES :
STYLE :
COULEURS :
PAGES :
FONCTIONNALITÉS :
CONTACT :
CONTRAINTES :
RÉFÉRENCES :
```

Exemple minimal suffisant :

```text
[NOUVEAU PROJET]

CLIENT : Garage X
ACTIVITÉ : réparation automobile
LOCALISATION : Charlieu
OBJECTIF : obtenir des demandes de devis
STYLE : premium
```
